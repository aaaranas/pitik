# Y2K Zine Identity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give Pitik a Y2K-zine visual identity — ink as a structural material, Archivo 800 at real scale, an ornament kit, photographs as objects — and expand the booth strip caption to six faces.

**Architecture:** A personality layer over the shipped pastel system, not a rebuild. The palette, the 29-pair contrast gate and every behaviour survive. Ornament is added first (`.slab`, `.blk`, `.rule-ink`, `.sticker`, `.tape`, `.polaroid`, `.counter`), screens migrate onto it one at a time, and `.pillow` is deleted last once nothing consumes it — the additive-then-subtractive pattern the previous refactor proved.

Unlike the previous refactor there is **no light/dark inversion window**: the ground is already light, so a half-migrated app is simply "some screens zine, some screens soft" — coherent at every commit, never broken.

**Tech Stack:** Next.js 16.3.1 (App Router), React 19.2.8, Tailwind CSS v4 (`@theme`), Radix (dialog, slider), lucide-react, next/font/google, Vitest + jsdom, Playwright.

**Spec:** [docs/superpowers/specs/2026-09-19-y2k-zine-identity-design.md](../specs/2026-09-19-y2k-zine-identity-design.md)

## Global Constraints

Every task's requirements implicitly include this section.

### Machine notes — read before running anything

- `git` and `bash` are **not** on the Bash-tool PATH. Use PowerShell, or full paths:
  git = `C:\Program Files\Git\cmd\git.exe`, bash = `C:\Program Files\Git\bin\bash.exe`.
- **Never kill or stop processes by name.** The user's own Google Chrome runs on this
  machine, and an earlier session force-closed it with a name-matched `Stop-Process`.
  Stop only a PID you launched, or filter on an ExecutablePath containing `ms-playwright`.
- **Do not touch `git stash`.** `stash@{0}` belongs to the user.
- Branch is `pastel-v2`. Do not switch branches.

### The palette does not change

No hex value is edited in this plan. The five pastels, the cream ramp and the cocoa ramp
are all solved values gated by `scripts/check-contrast.mjs`, which must stay at **≥29/29**.

### Colour rules (unchanged, still binding)

1. Pastel is for fills, tints and borders. Pastel is never small text unless it is `deep`.
2. Text on a pastel `base` fill is always `cocoa-900`.
3. `cocoa-400` is decorative/disabled only on cream.
4. A boundary that is a control's only affordance uses `edge-strong`, not `cream-300`.
5. **Dark surfaces invert**: on `cocoa-900`, body text is `cream-50`, muted is `cocoa-400`,
   accents take a pastel `base` not `deep`. Never `cocoa-400` on a `cocoa-800`/`cocoa-600`
   fill. Applies in `capture-viewer.tsx`, `booth-runner.tsx`, `clip-dialog.tsx` and
   `PermissionGate tone="dark"`. **Those surfaces stay dark — do not lighten them.**
6. A lit or active indicator on a pale ground reads **darker**, never brighter.

### The zine mapping

Every screen task applies this. It is the single source of truth.

| Old | New |
|---|---|
| `.pillow` card | `.slab` (+ a hue variant: `.slab-blush` / `-butter` / `-mint` / `-lilac`) |
| soft lozenge `.chip` | square `.chip` (restyled in Task 1 — same class name, new look) |
| `rounded-card` / `rounded-slot` on cards | `rounded-slab` |
| a section label / eyebrow | `.blk` (solid ink) or `.counter` (mono tracked caps) |
| a decorative divider | `.rule-ink` (3px, structural) or `.rule-dot` |
| a badge / "New" pill | `.sticker` |
| a photo container that is an *object* | `.polaroid`, optionally `.tape` |
| heading ≥2rem | `font-display` + `tracking-[-0.04em]` |
| blurred `shadow-*` on a card | the hard offset shadow `.slab` carries |

### Typography

- `font-display` is **Archivo 800**. Mixed case. At ≥2rem always pair with
  `tracking-[-0.04em]`; ink CTA blocks may use `uppercase`.
- `font-sans` (Plus Jakarta Sans) carries body copy **and all user-entered text** — roll
  titles, captions, names. Archivo's coverage is narrower and a CJK or emoji title would
  fall back mid-string. This rule survives.
- `font-mono` (DM Mono) is **promoted**: beyond counters and timestamps it now carries the
  zine's tracked-caps micro-labels (`REC ●`, `36 EXP`, `NO. 001`, `01` / `02`). This
  reverses the current CLAUDE.md wording and Task 11 rewrites it.

### Out of bounds

### Verification facts

- **Tailwind v4 emits nothing for a removed utility or token** — no error. A stale
  `.pillow` will lint, typecheck and build clean, then render unstyled. Completion is a
  grep, never a green build.
- The grep pattern must be **word-bounded**: `\b(pillow|...)`. Without `\b`, `shrink-0`
  falsely matches `ink-0`. This produced a false alarm in the last refactor.
- Unit tests are pure logic and reference no components.
- ESLint React Compiler rules are correctness requirements: no `setState` in an effect
  body, no `ref.current` during render, no impure calls during render.
- JSX apostrophes must be escaped as `&apos;` — `react/no-unescaped-entities` is on and
  has already broken one task.

  display: "ui-rounded, ui-sans-serif, system-ui, sans-serif",
  sans: "ui-sans-serif, system-ui, sans-serif",

 *
 * These faces set at very different x-heights. Cormorant and Dancing Script
 * are far smaller than Archivo at the same pixel size, so a caption would
 * visibly shrink just by choosing them. The multiplier keeps a caption the

  sans: 1,
  mono: 0.95,
  serif: 1.18,
  hand: 1.22,
  script: 1.2,

  return FONT_SCALE[kind];
}

- [ ] **Step 5: Force the face to load before canvas draws**

This is the part that silently breaks. Canvas falls back to a generic for a face the
document has not loaded, with no error, and a caption-only face downloads lazily.

`composeStrip` is synchronous and must stay so. `exportStrip` is already `async` and is
the **only** entry point — both the live preview (`strip-editor.tsx:110`) and the dev page
go through it — so the load belongs there.

Add above `exportStrip` in `src/lib/booth/compositor.ts`:

```ts
/**
 * Canvas draws with a generic when the chosen face has not loaded yet, and
 * says nothing about it. The interface never uses the caption-only faces, so
 * they download lazily — without this, the first strip composed after picking
 * Serif, Handwritten or Script would render in the wrong font silently.
 */
async function ensureCaptionFont(kind: StripStyle["captionFont"], px: number): Promise<void> {
  if (typeof document === "undefined" || !document.fonts) return;
  // document.fonts.load wants a single family, not a stack.
  const family = fontStack(kind).split(",")[0]?.trim();
  if (!family) return;
  try {
    await document.fonts.load(`${Math.max(1, Math.round(px))}px ${family}`);
  } catch {
    // A face that refuses to load is not a reason to fail an export —
    // the fallback stack still draws a readable caption.
  }
}
```

Then, as the first statement inside `exportStrip`, before it composes:

```ts
  await ensureCaptionFont(
    options.style.captionFont,
    (options.template.caption?.size ?? 16) * (options.scale ?? 1),
  );
```

Match the existing parameter names in `exportStrip`'s signature — if it destructures its
options, read the same fields off the destructured names instead.

## Typography

The app is dressed as a Y2K zine, not as a product page. Three faces for the
interface, all self-hosted through `next/font`, all declared once in `layout.tsx`:

- `font-display` (Archivo 800) is for our words — headings, the wordmark, ink

  the tracking is what makes it read as a masthead rather than a big paragraph.
- `font-sans` (Plus Jakarta Sans) carries body copy **and everything the user
  typed**. Roll titles, captions, names. Keep user text here: Archivo's character
  coverage is narrower, so an emoji or CJK roll title would fall back mid-string.
- `font-mono` (DM Mono) carries machine text **and the zine's micro-labels** —
  counters, timestamps, and the tracked-caps furniture (`REC ●`, `36 EXP`,
  `01` / `02`). Here it is deliberately decorative as well as functional.

for the booth strip caption and are never used by the interface. That is exactly
why `exportStrip` forces the chosen face to load before drawing: canvas falls back
to a generic for an unloaded face and reports nothing, and a caption-only face
downloads lazily. Each also carries a size multiplier, because these faces set at
very different x-heights and a caption would otherwise shrink just by being
restyled.

the Tailwind theme keys point at those. Keep the two names distinct — a
self-referential custom property silently resolves to nothing. Canvas cannot
read a CSS variable at all, so `compositor.ts` resolves the stack off the
document and falls back to generics in workers and tests.
